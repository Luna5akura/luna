title: Chrome Shortcut
---

| Action | Shortcut / Method |
| --- | --- |
| 左右组合两个标签页 | Chrome 没有“将两个标签页左右并排”的专用快捷键 |
| 把当前标签页分离成新窗口 | Chrome 没有默认专用快捷键；直接把标签页拖出当前窗口 |
| 把新窗口里的标签页合并回原窗口 | Chrome 没有默认专用快捷键；把标签页拖回另一个窗口的标签栏 |
| 新建窗口 | Windows / Linux: `Ctrl + N`；Mac: `Command + N` |
| 新建标签页 | Windows / Linux: `Ctrl + T`；Mac: `Command + T` |
| 关闭当前标签页 | Windows / Linux: `Ctrl + W`；Mac: `Command + W` |
| 恢复刚关闭的标签页 / 窗口 | Windows / Linux: `Ctrl + Shift + T`；Mac: `Command + Shift + T` |

备注：

- 如果你的目标是“左右并排看两个页面”，常用做法是先把一个标签页拖成新窗口，再用系统快捷键贴靠窗口。
- Windows 可用 `Win + Left` / `Win + Right` 把两个 Chrome 窗口左右贴边。
- Chrome 官方帮助目前只提供“拖出标签页到新窗口”和“拖回标签栏”的方法，没有提供对应的默认键盘快捷键。
