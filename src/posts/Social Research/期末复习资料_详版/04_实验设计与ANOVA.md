# 04 实验设计、内外效度与ANOVA

覆盖：10单元实验设计-1、11单元实验设计-2。

## 一、什么是实验

实验用来验证因果关系。课程中实验的三个要素：

1. 提出因果假设。
2. 改变情况或引入变化。
3. 比较变化和无变化下的结果。

实验适合的问题：

- 因果逻辑简单清楚。
- 可以清楚分离因果机制。
- 关注范围较窄。
- 微观、短期、影响因素较少。
- 自变量可被操纵。
- 符合伦理和现实条件。

不适合的问题：宏观长期政策、无法操纵的历史事件、高伦理风险、影响因素太多且不可控的问题。

实验研究流程：

1. Build hypotheses：提出假设。
2. Design the experiment：选择变量、流程、控制、随机化。
3. Operationalize independent variables：设计操纵。
4. Conduct the experiment：实施实验。
5. Data analysis and report：分析和报告。

## 二、实验术语

| 术语 | 定义 | 例子 |
|---|---|---|
| Factor 因素/因子 | 核心自变量 | 排序方式 |
| Level 水平 | 因素的取值或强度 | 升序、降序、随机 |
| Treatment 处理 | 各因素水平组合 | 降序+有图片 |
| Manipulation 操纵 | 改变因素水平的技术 | 给被试看不同排序页面 |
| Dependent variable 因变量 | 被测结果 | 购买意愿、质量感知 |
| Experiment unit 实验单位 | 接受处理的对象 | 被试、店铺、班级 |
| Control 控制 | 保持不变的条件或无处理组 | 同品牌、同价格信息 |
| Confounding/Covariate 协变量 | 影响结果但非焦点的变量 | 原有GPA、视力、经验 |

2×3实验有6个treatments，因为所有因素水平交叉组合。

## 三、实验核心流程与因果识别

实验的核心逻辑是让两组或多组除了操纵之外没有系统差异。基本形式：

```text
实验组：随机分配 -> 施加操纵 -> 测量因变量
控制组：随机分配 -> 不施加操纵或施加对照材料 -> 测量因变量
比较两组结果
```

排除替代解释的主要方法：

- 随机分配被试到处理组。
- 控制样本属性或环境条件。
- 使用协变量测量不能控制的因素。
- 保持实验材料、流程、时间、说明一致。
- 设计可比控制组。

随机分配不是随机抽样。随机抽样用于提高样本对总体的代表性；随机分配用于提高因果推断的内部效度。实验可以没有随机抽样，但不能轻易没有随机分配。

特征匹配法：在随机分配时确保两组在某个特征上分布一致，如性别、GPA。优点是匹配特征更均匀；缺点是无法保证其他特征，也可能不知道哪个特征重要。

控制与协变量原则：能控制则控制，不能控制则测量为协变量。协变量不应与焦点因素发生复杂交互，否则解释困难。

## 四、实验操纵

操纵类型：

- 指令操纵：给被试不同说明或阅读材料。
- 实物操纵：给被试不同真实物品。
- 经历/事件操纵：让被试经历不同过程。
- 属性差异：如性别、人格，本质上不是操纵，属于伪操纵或准实验因素。

自变量操纵是实验的核心。好的操纵要逼真、足够强、符合伦理，并尽量只改变目标构念。

连续型变量操纵的建议：

- 操纵力度要足够大，否则看不到理论效应。
- 但力度过大会降低现实性。
- 可让被试先形成价格、质量等分布感知，再给目标产品均值上下一个标准差。
- 考虑现实中感知阈值，例如小幅降价可能不足以改变价格感知。

优先使用成熟操纵。自创操纵必须pilot。

## 五、操纵检验

操纵检验回答：操纵是否成功改变了目标构念？

可以测：

- Awareness：被试是否注意到操纵。
- Perception：被试是否感知到操纵差异。
- Psychological impact：目标心理构念是否变化。

连续或次序型操纵检验可用t-test；离散型可用卡方检验。

预实验的目标：

- 验证操纵有效性。
- 验证测量工具有效性。
- 确保实验流程可执行。
- 询问被试，发现其他问题。

已经在预实验验证过的成熟操纵，不一定要在主体实验重新验证。若主体实验做操纵检验，通常先测因变量，再测操纵检验，避免操纵检验题提醒实验目的、污染因变量。

没有通过操纵检验的被试如何处理：

- 离散检验可考虑去除未通过者。
- 连续检验可考虑去除分布重叠严重样本。
- 处理规则应事前设定并报告，不能为了显著性随意剔除。

## 六、操纵效度

操纵效度包括：

- 聚合效度：操纵对目标构念产生显著效果。
- 区别效度/混淆效度：操纵不应同时强烈改变相似但非目标构念。

例如操纵“被拒绝感”时，还要测孤独感、愤怒、悲伤等相似心理状态。如果这些构念都同样强烈变化，就难以说明结果来自“被拒绝感”本身。

## 七、真实验设计类型

仅有后测的两组设计：

```text
R X O
R   O
```

R表示随机分配，X表示操纵，O表示观测。它常用于态度和意愿实验，因为前测可能暴露目的。

经典前后测设计：

```text
R O X O
R O   O
```

好处是可比较前后变化并控制初始差异；问题是前测可能使被试敏感，产生testing effect。

所罗门四组设计：

```text
R O X O
R O   O
R   X O
R     O
```

用于检验前测是否影响后测，但成本高，课程强调不常用。

多因素设计：

当有多个自变量时，考虑水平交叉组合。优点：

- 可检验交互作用，这往往是理论贡献所在。
- 两个自变量共享样本，节省样本量。

若理论不假设交互作用，不一定需要多因素设计。

## 八、主效应与交互效应

主效应：某个因素整体上对因变量的影响。

交互效应：一个因素的作用因另一个因素水平不同而变化，也就是“差中之差”。

例：服务质量从低到高，男性小费增加100，女性小费增加190。性别改变服务质量对小费的作用，交互效应为190-100=90。

判断图形：

- 两条线平行：无交互。
- 两条线斜率不同：有交互。
- 两条线交叉：交互强，可能方向反转。

## 九、多因素ANOVA

双因素实验的数据结构：

| 被试ID | 操纵A | 操纵B | Y | X1 | X2 |
|---|---|---|---|---|---|
| 001 | 1 | 1 | 7 | ... | ... |
| 021 | 1 | 2 | 5 | ... | ... |
| 041 | 2 | 1 | 3 | ... | ... |

双因素ANOVA将总方差分解为：

```text
Total SS = SSA + SSB + SSAB + SSE
```

其中：

- SSA：因素A主效应。
- SSB：因素B主效应。
- SSAB：A×B交互作用。
- SSE：误差。

看方差分析表中的F-test即可判断因素A、因素B和交互项是否显著。解读时还要看组均值和交互图，不能只看p值。

SPSS关键输出：

- Descriptives：各组均值和标准差。
- Tests of Between-Subjects Effects：主效应和交互效应显著性。
- Estimated Marginal Means和Plot：交互作用方向。

## 十、单因素ANOVA与多重比较

若一个因素只有两个水平，可用t-test。若多于两个水平，应先做ANOVA检验整体差异：

```text
H0: L1 = L2 = L3
Ha: 至少有一组不同
```

不能对A、B、C、D四组直接做六次t-test，因为多次比较会提高family wise error rate。例如每次错误率0.05，做4次独立比较时至少一次误判概率约为1-(1-0.05)^4=0.226。

多重比较方法：

| 对比需求 | 方法 |
|---|---|
| 所有组两两比较 | Tukey HSD |
| 所有组与控制组比较 | Dunnett |
| 部分两两比较，无控制组 | Dunn或Bonferroni思路 |
| 任意数量对比或非两两对比 | Scheffe |

Bonferroni思想：把每次比较的alpha调为0.05/比较次数，但通常较保守。

## 十一、内部效度

内部效度指实验是否能支持因果推断。常见威胁：

| 威胁 | 含义 | 例子 |
|---|---|---|
| History | 实验过程中外部事件影响结果 | 年末、疫情、市场变化 |
| Maturation | 时间本身带来自然变化 | 学生自然进步、病人自然康复 |
| Testing | 多次测试让被试熟悉测量 | 前测本身成为练习 |
| Instrumentation | 测量工具或评估者变化 | 前后评分标准不同 |
| Demand characteristics | 被试猜到目的并改变行为 | 霍桑效应 |
| Statistical regression | 极端样本自然回归均值 | 成绩差者自然改善 |
| Selection | 组间起点不同，非随机分配 | 主管挑可靠员工在家办公 |
| Mortality/Attrition | 退出者与留下者不同 | 办公室组离职更多 |
| Confounding | 外部变量同时影响X和Y | 公司生意变化影响绩效 |

诊断题答法：逐条指出威胁，并说明材料中对应证据。

例：2019-10-15到2020-01-15比较在家办公与办公室办公绩效，存在history（年末、新冠疫情）、selection（主管选择可靠员工）、instrumentation（主管评分变化）、maturation（经验增长）、mortality（离职比例不同）、demand characteristics（员工知道被比较）、confounding（业务环境变化）。

## 十二、外部效度

外部效度指因果关系能否推广到更大人群和真实情境。

常见威胁：

- 人为情境：实验室环境太不自然。
- 人为处理：处理方式现实中不可操作或强度过大。
- 样本特殊：大学生样本不能代表全部消费者。
- 任务低风险：虚构购买和真实购买中的金钱、售后、品牌、预算不同。

提升方式：

- 使用更真实材料和任务。
- 做田野实验或自然实验。
- 多样化样本。
- 报告推广边界。
- 在多个情境重复研究。

## 十三、自然实验与DID提示

自然实验是现实中出现类似实验处理的事件，研究者没有主动分配处理。它可提升现实性，但内部效度取决于是否能排除history、maturation、selection、confounding等。

DID可控制对处理组和控制组共同发生的历史事件或成熟效应，但不能自动控制只影响一组的事件。不能简单把“时间前后”说成控制history effect，因为真正要控制的是未知外部事件，而不是时间变量本身。

## 十四、实验设计题模板

1. 研究问题和因果假设。
2. 因素、水平、处理数量。
3. 被试和实验单位。
4. 随机分配方式。
5. 操纵材料和流程。
6. 控制组设计。
7. 操纵检验。
8. 因变量测量。
9. 协变量和控制变量。
10. 数据分析：t-test、ANOVA、多重比较、交互图。
11. 内部效度和外部效度威胁。
12. 伦理说明。
