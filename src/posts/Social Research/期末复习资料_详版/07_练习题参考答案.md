# 07 练习题参考答案

## 一、概念辨析题

1. 探索回答“是什么”，如“元宇宙经济体系有哪些组成”；描述回答“怎么样”，如“大学生短视频使用结构如何”；解释回答“为什么”，如“社交比较为何提升焦虑”；评价回答“是否有效”，如“限时折扣是否提升销量”。

2. 前者偏基础研究，关注机制；后者偏应用研究，关注具体决策。二者可结合。

3. 领域最大，主题更具体，研究问题是可观察、范围适中的问句。可改为：“生成式AI推荐解释如何影响用户对平台的信任？”

4. 实证研究用可观察数据和透明方法回答问题。社会现象复杂、样本和测量有误差，所以结论是证据支持下的概率判断。

5. 概念化是定义隐私担忧，如个体担心个人信息被过度收集、滥用或泄露；操作化是设计问项，如“我担心平台会未经许可使用我的个人信息”。

6. CPI构成性；信任多为反映性或二阶反映性；产品质量视定义可构成性；购买意愿多为反映性。

7. 信度高、效度低。

8. 聚合效度是同构念问项聚在一起；区别效度是不同构念分得开。加载到同一因子说明区别效度不足。

9. 随机抽样提高外部效度；随机分配提高内部效度。

10. 前半句满意度是中介；后半句会员等级是调节。

11. 外部效度是能否推广。大学生样本、虚构网页、无真实支付风险、任务短期都限制推广。

12. 内容分析负责把年报文本编码为变量；编码后的结构化变量进入回归时就是二手数据分析的一部分。

13. 民族志参与更深，理解文化和局内人意义，常单一群体长期观察；案例研究参与较浅，研究真实情境中的过程和机制，可单案例或多案例。

14. 行动研究。

15. 三角验证是用多个受访者、资料来源、时间点、案例、正反材料支持同一发现。它减少单一证据偏差。

## 三、流程与步骤题

41. 关键词如social media comparison、upward comparison、college students、anxiety；限定心理、传播、信息系统数据库；先找综述和近十年顶刊；追参考文献和被引；记录纳入标准。

42. 定义概念 -> 归纳流派或发现 -> 对比共识分歧 -> 指出gap -> 连接本文模型。

43. 构念定义 -> 生成或复用问项 -> 表面效度 -> pre-test -> blind sorting -> informed sorting -> pilot test -> 修订。

44. Blind sorting不告知构念数量和定义，让评委自然分类；informed sorting告知构念定义和数量，让评委归类到目标构念。都要讨论并计算一致度。

45. 目标总体可为上海大学生；研究总体为上海高校在读本科生；抽样单位为学生或班级；抽样框为学生名单、班级名单或学校名单；层可为学校、年级、性别。

46. 确定n，计算i=N/n，随机起点r，抽r、r+i、r+2i。列表有周期性时不适用。

47. 分层先按层分组再层内随机抽，保证层代表性；集群先随机抽群组再调查群组成员，成本低但精度较低。

48. 数据清洗 -> 缺失/无回复偏差处理 -> 信效度检验 -> 删除低质量item -> 计算构念值 -> 检查共线性和分布 -> 回归检验。

49. 做PCA/EFA，按eigenvalue和scree plot判断因子数，旋转，检查载荷、跨载荷、聚合/区别效度，删除问题item，检查alpha。

50. Y=cX；M=aX；Y=bM+c'X。X对M、M对Y显著，间接效应ab或c-c'显著即中介；c'显著为部分中介，不显著为完全中介。

51. 方程Y=a+b1X+b2Z+b3XZ。对X、Z中心化后构造交互项，检验b3；画Z高低水平下X-Y斜率。

52. 研究问题、假设、因素/水平、实验单位、随机分配、操纵、控制组、操纵检验、因变量、协变量、分析方法、内外效度、伦理。

53. 操纵检验判断操纵是否改变目标构念。预实验必做，自创操纵尤其需要；连续变量用t-test，离散变量用卡方检验。

54. 后测两组：R X O / R O。经典：R O X O / R O O。所罗门四组：R O X O / R O O / R X O / R O。

55. 总方差分为A主效应、B主效应、A×B交互、误差。关注F-test、p值、组均值和交互图。

56. Tukey用于所有两两比较；Dunnett用于与控制组比较；Dunn/Bonferroni用于部分两两比较；Scheffe用于任意或非两两对比。

57. 明确新闻来源和时间；单位为文章或段落；编码老年人形象、能力、依赖、负面词、角色；训练编码者；计算一致度；分析媒体类型或时间差异。

58. 搜索数据 -> 理解定义 -> 构建变量 -> 检查缺失、口径、效度、偏差、领域知识 -> 标准化 -> 回归/事件/面板分析。

59. 准备、开始、进入、成功策略、观察记录、访谈、离开、报告。四要素：关系、观察、对话、记录。

60. 多受访者、多资料来源、多时间点、多案例、正反材料、研究者交叉分析。

## 四、综合诊断题

61. 问题过宽；变量过于人口统计化；因变量二元且信息少；缺少机制。可改为“创业自我效能如何通过创业态度影响大学生创业意愿”，加入风险感知、主观规范等。

62. “很可靠”可测平台信任；“很有名”更像声誉；“我喜欢”是态度；“愿意购买”是购买意愿。构念混淆，应分构念设计多问项。

63. 本校课堂样本不是全国消费者概率样本。方案一：改目标总体为本校学生并承认方便抽样。方案二：建立全国消费者抽样框或使用分层抽样/专业样本库。

64. 控制组无材料导致阅读与否混淆；应给可比中性材料或低透明度材料；需要随机分配、操纵检验、控制算法任务、测信任量表。

65. ANOVA显著只说明至少一组不同；要用Tukey或预设比较检验A与B、A与C。

66. 词频可能只反映披露语言，不等于实践；需编码规则、同义词、语境、编码信度；股价受多因素影响，需控制行业、规模、财务指标和内生性。

67. 单一CIO证据不足，缺三角验证。应访谈CEO、CIO、业务部门，收集会议纪要、项目文档、组织结构和新闻材料。

68. 过度卷入或土著化，失去分析距离。应保持陌生人心态，记录自身位置和反思，避免替群体站队。

69. 实践背景不能替代理论机制。应定义感知有用性和使用意愿，引用理论如TAM，说明有用性如何降低成本或提高收益，从而增强意愿。

70. 可能是反向因果、第三变量、共同方法偏差、选择偏差、测量误差、时间顺序不清、共线性或伪相关。

## 五、研究设计题要点

71. 研究问题：评论数量如何影响大学生内容可信度。模型：评论数量 -> 感知社会认同/热度 -> 可信度，可加内容质量为控制。问项测社会认同、可信度；评论数量可自报感知或实验材料。抽样限定大学生，报告抽样方式。分析可用回归和中介。

72. 2×2实验：面额高/低，门槛高/低。处理4个。操纵材料保持产品、价格、页面一致。操纵检验测感知面额吸引力和门槛限制。因变量使用意愿。双因素ANOVA检验主效应和交互。效度威胁包括材料现实性、样本、需求特征。

73. 数据来源为外卖平台评论。分析单位可为单条评论或句子。编码配送慢、缺漏、态度差、食品质量、补救、评分。训练两个编码者，计算一致度。分析可用回归或有序模型。

74. 数据来源：年报提及隐私技术、Wind股价。变量：隐私技术投资编码、超常收益或股价反应、控制规模、行业、财务指标。检查年报口径、披露偏差、时间对齐。方法可事件分析或面板回归。内生性包括好公司更可能投资也更可能涨价。

75. 案例选择：数字化转型成效高低不同企业，理论重复。访谈CEO、CIO、业务负责人、IT团队；收集项目文件、会议纪要、组织架构、新闻。编码CEO支持方式、资源、权力、CIO有效性。三角验证多受访者、多资料、多案例。形成命题如“CEO赋予CIO高层地位提升CIO跨部门协调有效性”。
